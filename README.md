# Popular High School — Computer Academy

A responsive front-end website concept using the supplied Popular High School logo and reception photo.

## Run it
Open `index.html` in a modern browser. No build tools are required for this preview.

## Included demo interactions
- Responsive home page and course cards
- Course lesson preview modals
- Keyboard-shortcut practice activity
- Five-question sample quiz with instant demo score
- Student login preview and dashboard

## Demo login
- Student ID: `PHS0001`
- Password: `Learn@123`

**Important:** This is a front-end demo only. The sample login is hard-coded in `script.js` and is NOT secure. Do not use it for real student records. Real student accounts for 1,000 students, secure login, saved progress, examination records, and teacher/admin access require a backend, database, and server-side authorization (for example Supabase with Row Level Security).

## Suggested next step
Connect a properly configured backend, implement secure Student ID authentication, add teacher/admin roles, and test authorization before importing any real student data.
